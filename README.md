# aquaborn

> **⚠️ Legacy-проект.** Это старый, давно написанный сайт доставки питьевой воды **AquaBorn** (aquaborn.ru) — статический PHP-лендинг с формой обратной связи и слайдером диспенсеров. Репозиторий **актуализирован** (обновлены зависимости, закрыты уязвимости, мигрирована сборка) по состоянию на сегодняшнее число. Важно понимать: если бы такой сайт писали с нуля сегодня, архитектура и стек были бы совсем иными — это точечная поддержка существующего проекта, а не современная реализация.

## Структура

```
src/
├── index.php          # Главная страница
├── mail.php           # Обработчик формы обратной связи (отправка e-mail)
├── popup.php          # Модальное окно формы заказа
├── slider.php         # Слайдер диспенсеров из CSV
├── coolers/
│   ├── coolers.csv    # Данные диспенсеров (UTF-8): id;название;ссылка
│   └── images/        # Картинки диспенсеров
├── sass/              # Исходные стили (SCSS)
├── css/               # Собранные минифицированные стили (styles.min.css)
├── js/                # Скрипты (site.js, owl.carousel, bootstrap)
└── .htaccess          # Конфигурация Apache + security-заголовки
```

## Требования

- PHP 7.4+ (проверено на PHP 8.x)
- Node.js 14+ и npm (только для разработки/сборки стилей)
- Apache с включёнными `mod_rewrite` и `mod_headers` (для `.htaccess`)

## Установка и сборка

```bash
npm install          # установка зависимостей (dart-sass, gulp и плагины)
npx gulp styles      # однократная сборка src/css/styles.min.css из SCSS
npx gulp             # режим разработки: watch + BrowserSync (proxy aquaborn.local)
```

Сборка переводит SCSS → минифицированный CSS с автопрефиксами и попадает в `src/css/styles.min.css`.

> Примечание: SCSS переведён с устаревшего `@import` на модульную систему `@use`. Базовые стили вынесены в `_base.scss`, а порядок `@use` в `styles.scss` задаёт каскад (media-запросы идут после базовых стилей), поэтому адаптивность не нарушена.

## Конфигурация почты

Получатель и отправитель заданы в `src/mail.php`:
- `$mail_to` — почта, на которую приходят заявки (по умолчанию `all-coolers@yandex.ru`).
- `$subject` и `$headers['From']` — тема и отправитель.

Требуется рабочий `mail()` на хостинге (или локальный SMTP, если `mail()` недоступен).

## Безопасность

В рамках обновления проекта реализовано:

- **Валидация и санитизация** входных данных формы, защита от email-header injection.
- **CSRF-защита**: токен в сессии + скрытое поле в форме, проверка `hash_equals` в `mail.php`.
- **Honeypot-поле** и rate-limiting по сессии для защиты от спама.
- **Экранирование вывода** в `slider.php` (`htmlspecialchars` для данных из CSV).
- **Обновлены фронтенд-библиотеки**: jQuery 3.7.1 и Bootstrap 4.6.2 (с SRI) вместо уязвимых jQuery 3.4.1 / Bootstrap 4.0.0.
- **`.htaccess`**: HTTPS-редирект, security-заголовки (X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, базовый CSP), запрет листинга директорий.

## Деплой

Скопируйте содержимое `src/` в корень сайта на хостинге (например, `public_html/`). Убедитесь, что:

1. Каталог с файлами доступен для записи (для сессий PHP) или настроен отдельный каталог сессий.
2. На хостинге разрешён `mail()`.
3. Работает HTTPS (настроен SSL-сертификат), иначе уберите или адаптируйте редирект в `.htaccess`.
